Optional cover images for journal posts.

To give a post a cover photo, add an image here whose filename (without the
extension) matches the post's slug — the part of the markdown filename
after the date. For example:

  src/content/blog/2026-08-16-welcome-to-my-journal.md
  src/assets/images/blog/welcome-to-my-journal.jpg

A post without a matching image here simply has no cover — that's fine too.
