Each subfolder here becomes a category tab on the Gallery page.

- Drop a photo into an existing folder (landscape/ nature/ portrait/ street/)
  and it appears in that category automatically.
- Create a brand-new folder (e.g. "wedding/" or "wildlife/") and it becomes
  a brand-new category tab automatically — no code changes needed.
- The image's filename becomes its caption, e.g. "misty-coastline.jpg"
  shows as "Misty Coastline". Use dashes or underscores between words.

Just rebuild after adding photos (pushing to GitHub does this automatically
via the included GitHub Actions workflow).
