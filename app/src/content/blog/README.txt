Drop a new Markdown (.md) file here to publish a journal entry — no code
changes needed, just rebuild (pushing to GitHub does this automatically).

Filename convention: YYYY-MM-DD-your-post-title.md
  e.g. 2026-09-02-shooting-the-blue-hour.md

Required frontmatter at the top of the file, between --- lines:

  ---
  title: Your Post Title
  date: 2026-09-02
  excerpt: A one or two sentence summary shown in the journal list.
  ---
  The rest of the file is the post body, written in a light subset of
  Markdown: # headings, **bold**, *italic*, [links](https://example.com),
  ![images](https://example.com/photo.jpg), and "- " bullet lists.

Optional cover image: add an image with the same slug (the part of the
filename after the date) to src/assets/images/blog/ — see the README.txt
in that folder for details.
