# AabiaHasan.github.io

Aabia Hasan's photography portfolio — a plain HTML/CSS/JS site (no
framework, no build step) with a rotating hero gallery, filterable photo
gallery, About page, Contact form, and Journal.

Open `index.html` in a browser to preview it — see
[`PHOTOGRAPHY_SITE_GUIDE.md`](./PHOTOGRAPHY_SITE_GUIDE.md) for how to add
photos, publish journal posts, and deploy to GitHub Pages.

The old React version of this site previously lived in `app/` — it's no
longer used; see `app/DEPRECATED.txt`.
